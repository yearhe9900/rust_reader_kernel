# ROADMAP：范围、明确不做与待办

> 目的：让对接方**不用猜**——哪些能力将来会有、哪些明确不会有（以及为什么）。
> 结论若变，先改本文再动代码。

## 已落地（截至 v0.1.x / ABI 8）

- 格式：EPUB3/EPUB2、TXT（多编码）、MOBI/AZW3、CBZ（12 种页扩展名白名单）、PDF（自研解析+光栅）
- 重排管线：清洗 → 块模型 → parley 排版 → 分页/进度/命中测试；三要素布局缓存
- 内容级缓存（目录/章文本/大纲，issue #12）、稳定错误码（issue #11）
- 检索：全书拉模式搜索（可取消）、BM25 分步构建/落盘/重载、轻量单章搜索
- 第三方接入面：C 头文件 `bindings/rrk.h`、线程安全契约文档、进度/UTF-16 映射/
  选区取文 API、图片缩略图、排版可取消、`rrk_stats` 观测

## 明确不做（附理由）

| 能力 | 结论 | 理由 |
|------|------|------|
| **DRM 解密**（Adobe/Amazon/苹果等） | 不做 | 合法与专利风险；内核遇 DRM 一律 `UnsupportedFormat`（1002）明确拒绝，不静默失败。宿主可在应用层提示 |
| **PDF 表单填写 / 数字签名 / 注释编辑** | 不做 | 阅读器场景只需要渲染与文本提取；表单/签名涉及 JS 执行与密码学，复杂度与攻击面不成比例 |
| **PDF 加密（口令）文档** | 暂不支持 | 同属密码学面；如出现真实需求，以「独立可选特性 + 明确审计」另行立项讨论 |
| **固定版式 EPUB（rendition:layout=fixed-paginated）** | 不做 | 等价于「带重排元数据的 CBZ」——宿主可走 `PagedSource` 视图自行处理；内核投入产出比低 |
| **EPUB3 Media Overlays（音画同步朗读）** | 不做 | 小众出版形态，宿主无消费场景 |
| **TTS 分句 / 朗读边界 API** | 暂不立项 | 分句规则高度依赖语言与产品口径，属应用层；正文/坐标 API 已足够宿主自行切分 |
| **内核内落盘**（缩略图库、索引文件、翻译缓存） | 永久不做 | 红线：内核只产出字节，落盘/缓存策略归宿主（方案 §0.3）。BM25 索引、布局缓存均遵守 |
| **闭源依赖 / 预编译黑盒**（pdfium、mupdf、unrar…） | 永久不做 | 红线：纯 Rust、可审计、可 fork、许可宽松（方案 §3.2） |

## 语义承诺（对接方可依赖）

- **ABI**：符号与语义只增不改；`rrk_abi_version()` 相等校验；Dart 封装同步 bump
- **错误码 / 图像格式码**：只增不改（README 码值表）
- **缓存 payload**：自带 schema 号，升级/损坏自动失效重算，无需宿主迁移
- **坐标系**：章文本 UTF-8 字节偏移为内核原生坐标；UTF-16、进度百分比为
  可靠换算层（`rrk_map_offsets` / `rrk_progress_of`）
