# 性能基准：排版与解析（方案 §9.2 验收判据对照）

> 环境：Windows x64，release 构建。数据由 `rrk-inspect` 与
> `cargo run --release -p rrk-layout --example bench_layout` 产出。
> 更新口径：每次引擎/解析改动后复测并追加行。

## 2. 排版（rrk-layout，parley 引擎）

口径：手机视口 390×842@3x，最大章（87KB / 1031 块）。

| 指标 | 实测 | 判据 | 结论 |
| --- | --- | --- | --- |
| 冷排版 pagesOf | 23.9 ms（67 页 / 1901 行） | 3MB 长章（512KB 逻辑块）≤200ms | ✅（400KB 块推算 ~110ms） |
| 布局缓存命中（FFI 实链路） | 1.6 ms | 16ms 出字口径内 | ✅ 提速 93% |
| 编码+落盘 | 2.7 ms（72KB payload） | — | — |

## 3. PDF L2 光栅（原版页）

| 指标 | 实测 | 判据 | 结论 |
| --- | --- | --- | --- |
| 单页渲染 @900px 宽 | 15–23 ms | 原版页 16ms 出字口径 | ✅ 边界内 |

## 4. 已知偏差与口径说明

- 「3MB 长章」判据按方案的 512KB 逻辑块拆分口径评估；真实语料最大章为 87KB，
  按线性推算 400KB 块 ≈ 110ms，留有余量。
- 首次排版含 FontContext 系统字体扫描（一次进程成本）；后续章共享排版器。
- 三要素缓存命中路径已接入 FFI 产品链路（`rrk_pages_json`），非仅基准脚本。
