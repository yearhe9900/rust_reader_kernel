## 1. 统一目标与性能预算

| 指标 | 目标 | 来源 |
| --- | --- | --- |
| 点书卡 → 首次出字 | 热 ≤ 150ms（P50）/ ≤ 300ms（P95）；冷 ≤ 600ms | 全链路 §0.1 |
| 目标页就绪 | ≤ 1 帧（`paged.prime` 首页；`initialReady` 由 5 页放宽到目标覆盖） | 渲染层 §4.2 |
| 翻页 / 滚动 | 120Hz 零掉帧（1% low ≥ 90fps）；翻页帧耗时 P95 ≤ 8ms | 两份合并 |
| 长段落翻页 | 帧耗时与「段跨页数 k」**无关** | 渲染层 §6（A 档判据） |
| 导入上书架可点 | ≤ 500ms（壳），全量精修后台 | 全链路 §3 |
| 重开书命中 | 页表命中率 ≥ 90%（布局落盘后免测量） | 渲染层 §6 |
| 内存稳态 | 阅读页 RSS ≤ 150MB；3MB 长章峰值 ≤ 200MB | 两份合并 |
| 图片失效 | 一张图入表 ⇒ 重分页章数 = 1 | 渲染层 §6 |

## 2. 总体架构（终态，现行逐步对齐）

```
┌────────────────────────────────────────────────────────┐
│ UI 壳层（Flutter）  书架 / 阅读页 / 手势 / 动画（只合成）   │
├────────────────────────────────────────────────────────┤
│ 会话层    ReadingSession + TaskScheduler（优先级/可取消）  │
├────────────────────────────────────────────────────────┤
│ 引擎层（计算面，Rust 化演进）                              │
│   FormatAdapter → ChapterSource → ContentProcessor      │
│   → LayoutEngine（测量/切页）→ RenderScene（页/行绘制）    │
│   渲染四层：测量 → 切页 → 调度 → 挂载（§4 细化）           │
├────────────────────────────────────────────────────────┤
│ 存储层    LibraryStore（进度/配置）· ContentStore（章块）   │
│           CacheStore（结构 MRSC / 布局缓存 / 缩略图）      │
└────────────────────────────────────────────────────────┘
```

**缓存体系（统一四级）**：

| 级 | 内容 | 策略 | 现状 → 终态 |
| --- | --- | --- | --- |
| C1 | 段落布局（painter/行高） | LRU 池，离窗即弃 | **无 → 新增**（A 档） |
| C2 | 页表/行表（`PaginatedChapter`） | LRU 5 章 + 保护集 + 按 bookId 驻留 | 已有 → + configHash 软保留 + 落盘（B 档） |
| C3 | 章正文（`ChapterCache`） | LRU 30 章 + 距离补齐 | 已有，不动 |
| C4 | 图片（字节 + 解码位图） | 字节 LRU 50MB；解码显式上限 + 限流 | 字节已有 → 解码纳管（B 档） |

**贯穿不变式**：UI 线程零重活（不测量/不解压/不解码）；永远有可显示的东西（快照→估算→真页）；后台任务可取消；缓存 key = 内容 × 样式 × 视口；进度走语义坐标 `(chapterHref, chapterPos)`。

## 3. 三阶段链路（终态设计 + 现状映射）

### 3.1 导入：建索引，不搬内容

- 两阶段：Stage A 壳 ≤500ms 上架（文件移动/硬链、zip 中央目录、TXT 行首采样）→ Stage B 后台精修（分章、字数、封面缩略、结构缓存）。
- 各格式：EPUB 随机读不预解压；TXT 流式分章记字节偏移；MOBI/KF8 解压痛挪导入期一次；PDF/CBZ 只建页索引。
- 现状映射：现行「导入即解析入池」保留为 Stage B 的一部分（`BookSourcePool` 复用不变）；新增的是**壳上架**与「建索引不搬内容」口径。

### 3.2 打开：三级交付 + 并发流水线 + 预载

- 三级交付：看见（版式快照）→ 可读（估算上屏）→ 精排（语义重锚替换，位移 < 1 行）。
- 四路并发：进度/配置/章索引 ∥ 目标章块解压 ∥ 清洗 ∥ 排版落位页 ±2；首帧合成不等排版全完。
- 冷启动预载：**开书就绪包** = 结构缓存 + 目标章块 + 进度配置 + 布局缓存 + 快照 + 字体度量；预载时机五处（启动 idle 最近 3~5 本 / 书架可见 / 阅读中相邻 / 闲时 / 导入顺手），内存预算 20~40MB LRU + mmap。
- 现状映射：开书并发（§2.107）与 `BookSourcePool` 零读盘重开已同源；**新增**是快照层、估算上屏与就绪包预载（`initialReady` 放宽是其第一步）。

### 3.3 渲染：按需渲染 + 零布局翻页

- 三级窗口：L0 可见带（立即挂）/ L1 缓冲 ±2 页 / L2 预测带（方向感知 ±1~2 章，只测不画）。
- 页内按需：段 painter 复用 + 行区间 paint（§4 核心）；翻页 = 切页对象 + 变换，动画期零测量（`freeze()` 只冻新测量）。
- 回收：页表可留（C2）、段 painter 必弃（C1）、解码位图限流（C4）。
- 现状映射：`PagedScroller` 挂载已按需；缺口是页内整段渲染（A 档补）与预测带（窗口 ±1 → 方向感知 ±2）。

## 4. 渲染层关键结构与流程（改造核心）

### 4.1 关键结构

```dart
class LayoutedParagraph {        // 段落布局对象：整段一次 layout，跨页共享
  final int paraIndex;
  final TextPainter painter;     // 含占位尺寸，同测量四支点（宽/样式/缩放/strut）
  final List<double> lineTops;   // 行顶 y，与 MeasuredLine 对齐校验
  int refCount;                  // 归零入 LRU
}

class ParagraphLayoutPool {      // LRU：段下标 → LayoutedParagraph
  LayoutedParagraph acquire(int paraIndex, ...);
  void release(int paraIndex);   // 超限淘汰 refCount==0 的最久者
}
```

配套：行表 TypedData 紧凑化（start/end/height/para 四列，长章 5 万行不再堆小对象）；`PaginatedChapter` 增记 `imageSrcs`（图片精准失效）。

### 4.2 渲染流程

1. `PagedScroller` 可见区间二分（视口 ± overscan，分级：慢滚 ±2 页 / 快滚 ±0.5 页；区间变化 < 半页不重挂）；
2. 每页 `PageContent` 对相交段落 `pool.acquire`（命中 O(1)）；
3. 自定义 RenderBox 用 `painter.paint(canvas, 行顶 − preHeight)`，`clipRect` 只露 `[页首行, 页末行]`；
4. 一致性由对拍钉死：「整段 Column 渲染 vs 行区间绘制」行顶 y 全等。

### 4.3 回收流程

页卸载 → 相交段 `release` → refCount 归零入 LRU → 字节上界淘汰即 `painter.dispose()`。页表 LRU 5 章 + 保护集纪律不变（`setProtected` 淘汰跳过窗口章——真机「章节跳动」教训）。占位 → 真页切换走语义重锚（禁单跳像素修正）。

### 4.4 复用与预加载机制

| 机制 | 现状 | 改造后 |
| --- | --- | --- |
| 段落布局 | 每页重建 | 池复用（跨 k 页只布局 1 次） |
| 测量 | 顺序逐段、prime 16ms 出 5 页 | 目标页 1 页即上屏；预测带「只测不画」 |
| 图片失效 | 一图清全缓存 | 按 `imageSrcs` 精准重排 |
| 页表 | 内存 LRU 5 章 | + configHash 软保留 + MRSC 布局段落盘 |
| 首屏 | 5 页线 | `initialReady` = 目标覆盖；5 页线降为后台目标 |

## 5. 执行面演进（Rust 计算面的进入时机）

**原则**：换的是计算面（解析/解压/测量/分页/缓存/图片），不是呈现面（合成/动画/手势留 Flutter——Skia/Impeller 本就是原生）。收益四条：无 GC、批量化（一次 FFI = 一个任务）、rayon 真并行、**布局产物 rkyv 可落盘（SkParagraph 不可序列化，冷启动免排版）**。

**分档进入**（与 `RUST-09`「排版分页不上 Rust」的关系 = 走变更流程，先测后引）：

| 档 | 内容 | 进入条件 |
| --- | --- | --- |
| 现状 | Rust 仅档位 3（检索+解析） | 不动 |
| C2-1 | 解压/分章/编码检测 Rust 化（只读链路延伸） | A/B 档后仍不达标 |
| C2-2 | 测量/分页 Rust 化（parley/cosmic-text + rayon） | C2-1 基准达标 + RUST-09 变更批准 |
| C2-3 | rkyv 布局缓存统一全部缓存 | C2-2 达标 |

数据面硬纪律：UTF-8 字节偏移跨边界、rkyv/TypedData 零拷贝、句柄化 API、panic 不跨界、FFI 往返 ≤ 2 次/首帧。自绘后端（C1）与 Rust（C2）不并行，若推 C 优先 C2。

## 6. 分阶段落地路线（合并迁移排序与三档）

### Phase 1：低成本高收益（不碰红线）
1. **A 档**：`ParagraphLayoutPool` + 行区间 paint（长段翻页 O(段)→O(行)）；
2. 图片精准失效（`imageSrcs`）+ 解码位图纳管（上限 + 限流）；
3. `initialReady` 放宽到目标页覆盖（1 页即上屏）；
4. 就绪包预载（先做「启动 idle 预载最近 3~5 本」= 把「预热下一章」扩成「预载最近书」）；
5. 标题测量缓存、可见区间防 churn。

**退出条件**：长段翻页帧耗时与 k 无关；翻页 P95 ≤ 8ms；一图入表重分页章数 = 1。

### Phase 2：动首帧哲学（需主理人拍板）
1. 三级交付（估算上屏 → 精排替换）+ 版式快照（关书存、开书贴）；
2. 布局缓存落盘（MRSC 布局段）——重开书零测量；
3. 窗口 ±1 → 方向感知预测带 ±(1~2) 章。

**约束**：替换不跳必须复用 §2.85 同一几何真值（防闪动回潮）；占位语义不换真标题（§2.74 判据不动）。**退出条件**：热开 ≤ 150ms；页表命中率 ≥ 90%；#24/#14 切书闪屏类不复现。

### Phase 3：执行面（动 RUST-09，走变更流程）
按 §5 分档 C2-1 → C2-2 → C2-3，每档基准数据达标才进下一档。若 Phase 1/2 指标已达标，本阶段**缓行**。

## 7. 边界情况与处理（统一）

| 边界 | 处理 | 归属 |
| --- | --- | --- |
| 章节过长（MB 级） | 行表 TypedData 紧凑化；测量优先目标段；超长段渲染层行组切片（语义偏移不动） | Phase 1 |
| 超长段落跨多页 | 段 painter 复用 + 行区间 paint | Phase 1 |
| 图片加载 | 精准失效；解码限流 + 降采样；失败 48×48 占位不阻塞 | Phase 1 |
| 快速连续翻页 | 方向预测带；动画期只冻新测量；`_jumpPaged` seq 作废保持 | Phase 1/2 |
| 占位→真实切换 | 语义重锚（红线）；占位语义保持 | 全程 |
| 转屏/改字号 | configHash 软保留旧页表（回切命中） | Phase 2 |
| 空段章/孤行章 | 真身判据 = 内容+页表就绪（不看段落数）——已有，保持 | 全程 |
| 图片章（ListView 通道） | 中期并入分页通道（图片高同步可知），消灭估高漂移 | Phase 2 |
| 慢滚停稳大跳（挂账 #8） | 语义坐标 + 停手余量（`keepScrollRemainder`）已同源；等真机留痕日志定位 | 挂账 |
| 冷启动从未预载的书 | ≤ 600ms 冷预算兜底；就绪包命中后按热口径 | 全程 |

## 附：一页速记

- **一条路线**：Phase 1（A 档渲染复用 + 图片精准失效 + 1 页上屏 + 就绪包预载）→ Phase 2（三级交付 + 快照 + 布局落盘）→ Phase 3（Rust 计算面，达标即缓行）。
- **一个架构**：UI 壳（Flutter）/ 会话层 / 引擎层（计算面）/ 存储层；缓存四级 C1 段 painter → C2 页表 → C3 正文 → C4 图片。
- **一套判据**：出字 150/600ms、翻页 P95 8ms、长段与 k 无关、命中率 90%、RSS 150MB；每条都有会变红的用例。
- **不变的红线**：语义坐标真值、语义重锚禁单跳、占位语义、保护集淘汰纪律、UI 线程零重活。
